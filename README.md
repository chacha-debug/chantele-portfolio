# Chantele Mucuio — Developer Portfolio

A personal portfolio website showcasing my software development projects, technical skills, academic achievements, and experience as a final-year Information and Communication Technology student.

**Live Portfolio:** [chantele-mucuio.vercel.app](https://chantele-mucuio.vercel.app/)

---

## About

This portfolio was designed and developed to present my work as a software developer in a way that is personal, interactive, and easy for recruiters and other developers to explore.

Rather than focusing only on a list of technologies, the portfolio highlights the projects I have built, the problems I have worked through, and what I have learned from each project.

---

## Design Approach

The portfolio combines a clean developer-focused layout with playful visual details and animation.

The goal was to avoid a generic template and create an interface that reflects how I approach development:

> **building · learning · debugging · improving**

The design is intentionally kept relatively minimal so that the projects and technical work remain the main focus.

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/chacha-debug/chantele-mucuio.git
```

Navigate into the project:

```bash
cd chantele-mucuio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:3000
```

---

## Building for Production

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```
